# Value Bot: футбольные ставки с перевесом на локальном сайте

Бот скачивает матчи и коэффициенты с [football-data.co.uk](https://www.football-data.co.uk), считает вероятности и показывает на сайте `http://127.0.0.1:8000`, **на что ставить и сколько**. Ставку, которую ты сделал, отмечаешь кнопкой «Поставил». После матча бот сам её рассчитывает и ведёт статистику: прибыль, ROI, CLV, просадку, кривую банка.

Всё работает у тебя на компьютере. Нет ни аккаунтов, ни API-ключей, ни кошельков. Наружу бот обращается только к football-data.co.uk.

## Как это устроено

```
football-data.co.uk ──► история 5 сезонов + fixtures.csv (ближайшие матчи с кэфами)
        │
        ├─► penaltyblog: Dixon-Coles (с затуханием по времени) ─┐
        ├─► penaltyblog: Pi-рейтинги                            ├─► ансамбль ──► вероятность
        └─► кэфы Pinnacle без маржи (метод Шина) ───────────────┘       │
                                                                         ▼
                        EV = вероятность × кэф − 1  → сигнал, если EV ≥ порога
                        сумма = доля Келли от текущего банка (с потолком)
```

* **Слой 1 (penaltyblog).** Dixon-Coles переобучается каждую неделю только на прошлых матчах. Pi-рейтинги обновляются матч за матчем.
* **Слой 2 (ансамбли).** Три варианта: взвешенное смешивание «рынок + Dixon-Coles + Pi», логистическая регрессия и XGBoost с изотонической калибровкой. Каждый учится на предыдущих сезонах и проверяется на следующем.
* **Выбор модели.** Для прогнозов берётся модель с лучшим log-loss на матчах, которых она не видела. Рынок она заменяет, только если обыгрывает его **больше чем на одну стандартную ошибку**. Иначе бот честно опирается на цену Pinnacle, и сигналы — это места, где кэф букмекеров выше честной цены рынка.
* **Рынки:** исход 1X2 и тотал 2.5. По азиатской форе модель показывает честные кэфы справочно, но сигналов по ней не даёт.

## Установка на Windows

1. Поставь **Python 3.12 или 3.13** с [python.org](https://www.python.org/downloads/). При установке отметь галочку «Add python.exe to PATH».
2. Скачай эту папку `football-bot`, например через `git clone`.
3. Дважды щёлкни **`run.bat`**.
   * В первый раз скрипт создаст окружение `.venv` и поставит зависимости точных версий из `requirements.txt` (несколько минут, несколько сотен МБ).
   * Потом откроется браузер на `http://127.0.0.1:8000`.
4. Первое обновление данных запустится само и займёт 1–3 минуты. Ход видно в верхней части страницы.

Остановить бота: закрыть окно консоли или нажать `Ctrl+C`. Linux и macOS: `./run.sh`.

Чтобы заходить **с телефона** в домашней сети, запусти `run.bat --host 0.0.0.0` и открой на телефоне `http://<IP-компьютера>:8000`. Windows спросит разрешение брандмауэра. Пароля у сайта нет, поэтому так делай только в своей сети.

## Как пользоваться

| Вкладка | Что там |
|---|---|
| **Сигналы** | Ставки с перевесом: исход, вероятность модели и рынка, кэф, **мин. кэф**, EV и рекомендуемая сумма. Кнопка «Поставил». |
| **Матчи** | Все ближайшие матчи: вероятности 1X2 и тотала, ожидаемые голы, вероятные счета, честные кэфы, азиатская фора. Нажми на исход, чтобы записать любую ставку. |
| **Мои ставки** | Журнал ставок. Расчёт автоматический, есть ручные кнопки ✓ / ✗ / ↺ на случай переноса матча. Кэф и сумму можно исправить. |
| **Статистика** | Всё, по сигналам бота, свои (без сигнала) и «все сигналы бота по 1 единице» — бумажный счёт, будто ты ставил на каждый. |
| **Модель** | Качество моделей вне выборки, бэктест текущих настроек, данные по лигам. |
| **Настройки** | Банк, доля Келли, потолок ставки, порог EV, диапазон кэфов, источник цены, рынки, лиги, частота обновления. |

**Порядок работы:**

1. Открываешь «Сигналы».
2. Смотришь кэф у своей конторы. Если он **не ниже «мин. кэфа»**, ставишь. Кэфы в fixtures.csv — снимок на момент выгрузки, они успевают сдвинуться.
3. Жмёшь «Поставил» и вводишь **реальный** кэф и сумму. Окно сразу пересчитает EV и предупредит, если по такому кэфу ставка уже невыгодна.
4. После матча, когда football-data выложит результат (обычно в течение 1–3 дней), ставка рассчитается сама.

## Как читать цифры

* **EV** — ожидаемая доходность ставки по оценке модели. +5% значит, что в среднем на 100 ₽ ожидается +5 ₽.
* **Мин. кэф** = (1 + порог EV) / вероятность. Ниже этого кэфа ставить не стоит.
* **CLV** (closing line value) — насколько твой кэф лучше честной цены закрытия Pinnacle. Это **главный показатель**: если CLV в среднем больше нуля, перевес реальный, даже когда ROI на короткой дистанции минусовой.
* **ROI ± X%** — плюс-минус одна стандартная ошибка. На 100 ставках ROI гуляет на ±10–15% просто от везения, поэтому выводы делай на сотнях ставок.
* **Бэктест** на вкладке «Модель» показывает, как текущие настройки сработали бы на прошлых сезонах (плоская ставка 1 единица). Там же таблицы с другими порогами EV и с каждой моделью по отдельности.

Реалистичные ожидания: хорошая модель угадывает 1X2 примерно в 50–55% случаев, и редко какая обыгрывает Pinnacle. Основной источник перевеса — кэфы букмекеров, которые выше честной цены рынка. Поэтому в настройках есть выбор «Кэф для расчёта EV». «Лучший по рынку» — максимум среди контор, у твоей конторы кэф может быть ниже.

## Безопасность

* Версии всех библиотек зафиксированы в `requirements.txt` и ставятся только с PyPI в отдельное окружение `.venv`.
* Данные скачиваются стандартным `urllib` только с `www.football-data.co.uk`.
* `penaltyblog` тянет зависимость `wrapper-tls-requests`, которая **при использовании скрейперов penaltyblog** скачивает нативную библиотеку с GitHub. Бот эти скрейперы не использует. Тест `test_penaltyblog_scrapers_stay_unused` проверяет, что этот модуль даже не загружается.
* Сайт по умолчанию слушает только `127.0.0.1`, то есть доступен только с твоего компьютера.
* Всё хранится в папке `data/`: `bot.db` (SQLite) и кэш CSV. Чтобы начать с нуля, удали `data/`.

## Ограничения

* В модели только лиги football-data.co.uk из списка в настройках. Кубков и еврокубков нет.
* Команде нужно хотя бы 6 матчей в лиге за последние 3 года. Поэтому у новичков лиги в первые туры прогноза нет.
* Матч, перенесённый больше чем на 60 дней, автоматически не рассчитается. Отметь его вручную.
* Это инструмент анализа, а не гарантия выигрыша. Ставь только те деньги, которые готов потерять.

## Для разработчика

```
fbot/
  config.py   лиги, пути, настройки по умолчанию
  data.py     скачивание и разбор CSV football-data.co.uk
  markets.py  рынки, снятие маржи (Шин), расчёт ставок, азиатская фора
  model.py    Dixon-Coles и Pi (penaltyblog), пошаговая проверка, ансамбли, метрики
  engine.py   конвейер обновления, сигналы, автоматический расчёт ставок
  stats.py    статистика ставок и бэктест
  server.py   FastAPI: JSON API + раздача сайта
  static/     сайт (HTML/CSS/JS без внешних зависимостей)
tests/        pytest + генератор синтетических лиг в формате football-data
```

```bash
python -m pip install -r requirements-dev.txt
python -m pytest            # тесты на синтетических данных, без интернета
python -m fbot update       # обновить данные из консоли без сайта
FBOT_SOURCE_DIR=папка_с_csv python -m fbot   # работать с локальными CSV вместо скачивания
```

Функцию снятия маржи `fbot.markets.shin_probs` (векторизованный метод Шина, совпадает с penaltyblog) можно взять как fair value и для других проектов.
